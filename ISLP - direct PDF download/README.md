## ✅ Steps (10 minutes, once)

- [ ] 1. Open the book's home page: **https://www.statlearning.com/** → the **"Download ISL with Python"** link.
- [ ] 2. That link goes to the author-hosted download page: **https://hastie.su.domains/ISLP/ISLP_website.pdf.download.html** → click through to the PDF.
- [ ] 3. Save it **outside this repo** (e.g. `Data Science Journey/books/ISLP.pdf`). ~600 pages; it's the authors' free copy, not yours to redistribute, and a large PDF bloats git history forever.
- [ ] 4. Bookmark the **[ISLP errata page](https://www.statlearning.com/errata-python-edition)** and check it whenever a formula looks wrong.
- [ ] 5. Install the companion package once: `pip install ISLP` (v0.4.1 on PyPI) — the labs load their data with `from ISLP import load_data`. Docs: https://islp.readthedocs.io/

> [!WARNING]
> **Link check (25 Sep 2026):** statlearning.com still links to the same `hastie.su.domains` download page the roadmap gives, so the address hasn't moved. I couldn't open the download page itself from here (the site blocks automated fetching), so if it fails for you, start from step 1 — statlearning.com always carries the current link.
